# X-Lab 飞书 PDF 合并插件

用于在飞书多维表格中合并当前表格视图勾选记录的 PDF 报销材料。

## 使用方式

1. 在表格视图左侧勾选记录，插件会自动显示每条材料的 PDF 数量、页数和合计页数。
2. 确认合计不超过 30 页，并检查插件生成的日期范围、合计金额和目标文件名。
3. 至少勾选两条记录后，点击“合并并写回第一条记录”。

插件会检查：

- 所选记录的“审批”均为“同意”；
- “发票抬头”一致且非空；
- “报销类目”一致且非空；
- “发票+订单截图+支付截图”均有附件且全部为 PDF；
- 合并后总页数不超过 30 页；
- 最早、最晚开票日期与报销金额均已填写。

合并结果写入第一条选中记录的“合并后材料PDF”字段。文件名格式为“抬头+类目+【最早日期-最晚日期】总金额”，日期取全部所选记录的最小值和最大值，金额为全部所选记录之和。文件只在当前浏览器内存中处理，不发送给第三方 PDF 服务。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
