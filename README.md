# X-Lab 飞书 PDF 合并插件

用于在飞书多维表格中合并当前表格视图勾选记录的 PDF 报销材料。

## 使用方式

1. 在表格视图左侧勾选至少两条记录。
2. 打开插件并点击“刷新选择”。
3. 确认插件显示的发票抬头、报销类目和文件数量。
4. 点击“合并并写回第一条记录”。

插件会检查：

- 所选记录的“审批”均为“同意”；
- “发票抬头”一致且非空；
- “报销类目”一致且非空；
- “发票+订单截图+支付截图”均有附件且全部为 PDF。

合并结果写入第一条选中记录的“合并后材料PDF”字段。文件只在当前浏览器内存中处理，不发送给第三方 PDF 服务。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
